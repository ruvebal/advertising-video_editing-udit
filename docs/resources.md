## How to Use This Library

This is the single canonical resource document for the course. It combines practical production tools, stock and sound libraries, AI-assisted workflows, platform references, theory, academic reading, and project-organization habits in one place.

Use it in this order:

1. Start with the fastest legal option.
2. Check attribution and commercial-use limits.
3. Keep a simple credit sheet for every project.

## License Attention

- **[Videvo](https://videvo.net):** item-level license differences matter.
- **[ccMixter](https://ccmixter.org):** attribution is often required.
- **[Freesound](https://freesound.org):** licenses vary by upload.
- **[Free Music Archive](https://freemusicarchive.org):** track-level licensing differs.
- **[BBC Sound Effects](https://sound-effects.bbcrewind.co.uk):** check current permitted-use terms.
- **[ElevenLabs](https://elevenlabs.io):** free testing and commercial rights are not the same thing.

### Simple Rule

- If the source is community-based, read the item license.
- If the source is AI-based, read the plan limits.
- If the work is public-facing, keep a credit sheet anyway.

## Community Best Practices

{% include tao-quote.html quote="The wise editor organizes before creating. Chaos in the project folder leads to chaos in the timeline." %}

### Project Organization

```text
PROJECT_NAME/
├── 01_RAW/
│   ├── Video/
│   └── Audio/
├── 02_SEQUENCES/
├── 03_EXPORTS/
├── 04_ASSETS/
│   ├── Music/
│   ├── SFX/
│   └── Graphics/
└── 05_ARCHIVE/
```

### Naming Conventions

- Use descriptive names: `SCENE01_INTERVIEW_JOHN_V02.mp4`
- Include version numbers
- Use dates in ISO format: `2025-01-14`

### Backup Strategy

- 3-2-1 Rule: 3 copies, 2 different media, 1 offsite

### Credit Sheet Habit

- Keep one text file or sheet per project with the source URL, creator/platform, license note, and attribution text if needed

### Recommended Starter Pack for Students

- **Music/SFX:** [Mixkit Music](https://mixkit.co/free-stock-music/) + [Freesound](https://freesound.org)
- **Stock visuals:** [Pexels Videos](https://www.pexels.com/videos/) + [Unsplash](https://unsplash.com)
- **Voice draft:** [TTSMaker](https://ttsmaker.com/)
- **AI experimentation:** [Runway](https://runwayml.com) or [Fliki](https://fliki.ai)
- **Color planning:** [Adobe Color](https://color.adobe.com) or [Coolors](https://coolors.co)
- **Storyboards:** [Storyboarder](https://wonderunit.com/storyboarder/)
